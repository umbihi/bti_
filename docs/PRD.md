Oct 29, 2026 (최신 업데이트) · @umbi

## 1. 목표와 성공조건

북극성 지표는 **7일 내 재진단 사용자 비율** 하나다. 로그인이 없으므로 "사용자"는 브라우저 단위 익명 ID로 정의한다(4장 계측 이벤트 참고). 설계 제약은 **운영자 API 비용 0원**이며, 모든 AI 호출은 제미나이 무료 티어의 한도와 약관 안에서 처리한다.

**문제 진술**: 신입·직무 전환 지원자는 문항 의도와 지원 직무 기준에 맞춰 자기 글을 점검할 수단이 없어, 같은 약점(결과 나열, 직무 연결 부재)을 회사마다 반복한다.

### 핵심 가설 (MVP가 검증할 것)

1. **가치 가설**: 사용자는 "다시 써주기"보다 "무엇이 부족한지 근거와 함께 짚어주기"를 더 신뢰하고 유용하다고 느낀다.
2. **반복 가설**: 고정 기준표와 **시즌 스트릭·레벨업 피드백** 덕분에 "수정 → 재진단" 루프가 돌고, 다음 회사 문항에도 다시 돌아온다.
3. **차별 가설**: 직군 선택과 직무명 입력만으로 범용 AI보다 구체적인 피드백이 나온다.

### 목표

- 문항 + 답변을 넣으면 10초 안에 기준표 진단과 수정 제안을 받는다.
- 같은 글을 다시 넣으면 판정이 대부분 같게 나온다(일관성).
- 처음 온 사용자가 5분 안에 무료 API 키를 연결하고 첫 진단까지 마친다.
- 운영자 비용 없이(정적 호스팅 + 사용자 본인 무료 키) 0·1단계를 운영한다.
- 게이미피케이션(연속 진단 스트릭, 업적 달성, 레벨업 연출)으로 재진단 및 리텐션을 촉진한다.

### 비목표 (MVP에서 하지 않음)

- 자소서 전문 대필 또는 답변 전체 재작성
- 회원가입, 로그인, 서버 기반 첨삭 이력 영구 저장
- 운영자 서버 운영, 운영자 명의 API 키로 실제 사용자 글 처리
- 유료 결제, 기업별 합격 자소서 DB 구축
- 초안 뼈대 생성(2차)

### 성공 지표

| 구분 | 지표 | 정의 |
| --- | --- | --- |
| 북극성 | 7일 내 재진단율 | 첫 진단 후 7일 안에 다른 날 다시 진단한 익명 ID 비율 (주간 스탬프 및 스트릭으로 촉진) |
| 보조 | API 키 연결 완료율 | 키 연결을 시작한 익명 ID 중 연결에 성공한 비율 (무료 발급 링크 및 안내 모달 제공) |
| 보조 | 세션당 진단 횟수 | 한 세션에서 진단 요청 성공 수 ("수정 → 재진단" 루프 횟수) |
| 보조 | 퀘스트 완료율 | 제안된 문장 수정 퀘스트 체크박스를 누른 비율 |
| 보조 | 피드백 긍정률 | 결과에 "도움됨"을 누른 비율 (아쉬워요 클릭 시 3가지 선택 사유 수집) |
| 가드레일 | 진단 실패율 | 진단 요청 중 오류·시간 초과 비율(한도 초과 제외) |
| 가드레일 | 무료 한도 초과율 | 진단 요청 중 429(분당/일일 한도 초과) 응답 비율 |
| 가드레일 | 판정 일관성 | 같은 입력 3회 진단 시 5개 항목 판정 일치율 (목표 80% 이상) |
| 가드레일 | 가명 처리 누락 | 전송문 내 가려야 할 개인정보가 남은 건수 (0건 필수, 주민번호 전송 차단) |

### 단계별 통과 기준

1. **0단계 · 엔진 검증**: [거의 완료] 프론트엔드 UI/UX 완성, 가상 자소서 30건(`qa/dataset.json`)으로 검증. 판정 일관성 92.5%(기준 80% 이상) · 환각 인용 필터 후 0건 · 가명 처리 누락 0건 · 주민번호 차단 100% 통과. 응답 p95 20초 기준은 꼬리 지연으로 미달(p50 4.8초, 호출의 8.3%가 20초 초과)이며, 하드 타임아웃을 30초로 상향해 대응(재측정 생략). 남은 것: 배포 URL에서 브라우저 CORS 최종 확인.
2. **1단계 · 클로즈드 사용 (사용자 본인 키)**: 본인과 주변 지원자 10~20명이 각자 무료 키로 실제 지원에 사용. 통과 기준: 키 연결 완료율, 재진단율, 피드백 긍정률 충족.
3. **2단계 · 2차 기능**: 초안 뼈대 생성, 다중 문항 일괄 관리.
4. **3단계 · 공개 여부 결정**: 사용자별 무료 키 모델 지속 여부 또는 유료 운영자 키 전환 검토.

## 3. 화면 명세

### 화면 구성 및 레이아웃

* **상단 헤더 (`Header`)**:
  * 소서핏 로고 및 β 배지, 한 줄 소개
  * 사용법 3단계 인디케이터 (1. 자소서 붙여넣기 → 2. 가명 처리 확인 → 3. 진단·수정 퀘스트)
  * 연속 진단 스트릭 배지 (불꽃 아이콘 + 연속 N일)
  * 업적 달성 카운트 버튼 (달성 수 클릭 시 시즌/업적 모달 오픈)
  * AI 키 상태 배지 (연결됨 / 키 없음)
  * 가명 처리 실드 활성화 태그
  * 라이트/다크 테마 토글 버튼
* **모바일 전용 네비게이션 바**:
  * '내 자소서' (입력) 탭 ↔ '진단 결과' 탭 전환
  * 새 진단 완료 시 '진단 결과' 탭에 펄스 알림 점(dot) 표시
* **좌측: 입력 패널 (`InputPanel`)**:
  * 상단: '예시 불러오기' 빠른 시연 버튼
  * 6개 직군 셀렉트 (`Select`) & 직무명 인풋 (2~30자)
  * 자소서 문항 텍스트에어리어 (5~500자)
  * 답변 영역:
    * **편집 모드 (`edit`)**: 50~2,000자 입력 에어리어
    * **읽기/진단 모드 (`read`)**: 판정 카드 클릭 시 근거 문장 하이라이트 및 수정하기 전환 버튼
  * 글자수 카운터 및 게이지 (`CharGauge`): 공백 포함/제외 토글, 최대 제한 대비 현재 글자수 바
  * '진단하기' / '무료 키 연결하고 진단하기' 메인 CTA 버튼
* **우측: 결과 패널 (`ResultPanel`)**:
  * **빈 상태**: 진단 전 안내 및 점검 항목 리스트
  * **스캔 로더 (`ScanLoader`)**: 분석 단계별 인디케이터 ("보통 10초 안에 끝나요")
  * **수정 알림 배너**: 답변 내용 변경 시 "수정 전 기준 결과입니다" 및 즉시 재진단 유도
  * **레벨업 카드 (`LevelUpCard`)**: 재진단 시 판정이 오른 항목 시각화 및 ALL CLEAR 달성 축하 연출
  * **문항 의도 섹션**: 평가 역량 1~2문장 요약
  * **능력치 판정 카드 (`StatCards`)**: 5개 항목(문항 적합도, 두괄식 구조, 경험 구체성, 직무 연결성, 회사 이해도) 3단계 게이지 및 근거 문장 연동
  * **수정 퀘스트 리스트 (`QuestList`)**: 문장 단위 원문 대조, 추천 수정문, 이유 설명 및 완료 체크박스
  * **피드백 바 (`FeedbackRow`)**: 도움이 됐어요 / 아쉬워요 (선택 사유 팝업)
  * **하단 액션 바**: "고친 답변 다시 진단" & "복사하고 다음 문항" 원클릭 버튼
* **모달 및 보조 도구**:
  * **무료 키 설정 모달 (`KeyModal`)**
  * **가명 처리 확인 모달 (`MaskModal`)**
  * **시즌 스트릭 및 업적 모달 (`SeasonModal`)**
  * **데모/상태 프리셋 플로팅 바 (`DevBar`)**
  * **글로벌 토스트 (`Toaster`)**: 업적 달성(`AchievementToast`) 및 피드백 알림
